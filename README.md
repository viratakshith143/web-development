## About This Repository
This repository contains three web development lab experiments created using **HTML and CSS**. These projects demonstrate the use of web page structure, styling, navigation bars, responsive layouts, product displays, and information sections.

## Experiments

### 1. Online Shopping Website – OrangeCart
**Aim:** To create an e-commerce website displaying products, prices, discounts, ratings, categories, product descriptions, and shopping buttons.

**Features:**
- Shopping navigation bar
- Promotional banners
- Product cards with images and prices
- Discounts and ratings
- Responsive product grid

### 2. College Information and Admissions Website – NRI Institute of Technology
**Aim:** To develop a college website displaying institutional information, departments, courses, faculty profiles, admission procedures, facilities, events, and contact details.

**Features:**
- College navigation bar
- Homepage banner
- Department and course information
- Faculty and facilities sections
- Responsive information cards

### 3. Bakery and Cake Shop Website – Sweet Crumbs Bakery
**Aim:** To design a bakery website displaying cakes, pastries, cookies, custom cake designs, product prices, seasonal offers, and contact details.

**Features:**
- Attractive bakery-themed design
- Product image gallery
- Cakes, pastries, and cookies sections
- Seasonal offers
- Contact information

## Technologies Used
- HTML5
- CSS3
- Visual Studio Code
- Web Browser

## How to Run the Projects
1. Download or clone this repository.
2. Open the required experiment folder.
3. Open the HTML file in a web browser.
4. View the website.
